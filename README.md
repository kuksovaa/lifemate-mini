# LifeMate Mini

**LifeMate Mini** - учебный прототип персонального цифрового помощника, который помогает сохранять события жизни, хранить информацию о людях, отслеживать встречи и получать рекомендации по интересам.

Проект разработан в рамках курса ВШЭ.

## Идея проекта

LifeMate задуман как персональная память человека. В будущем он сможет объединять дневник, события, интересы, привычки и другие данные, чтобы формировать контекстные рекомендации.

Текущая версия **0.1.0** — небольшой REST API на FastAPI. В ней используются простые правила Python, без подключения настоящей ИИ-модели.

## Функциональность

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Приветствие |
| GET | `/health` | Проверка работоспособности |
| GET | `/version` | Версия приложения |
| GET | `/journal` | Просмотр дневника |
| POST | `/journal` | Добавление записи с датой события |
| GET | `/people/{name}` | Поиск человека |
| POST | `/people` | Добавление человека |
| GET | `/reminders?days=30` | Напоминания о давних встречах |
| GET | `/ideas/{interest}` | Рекомендации по интересам |

Дата создания записи фиксируется автоматически. Дату события можно указать самостоятельно. Для текста со словом «сегодня» дата события определяется по текущему дню.

## Технологии

- Python 3.12
- FastAPI — создание API
- Uvicorn — запуск веб-сервера
- Pydantic — проверка входящих данных
- uv — управление зависимостями
- pytest — автоматическое тестирование
- Git — контроль версий

## Установка и запуск

Для работы нужны Python и [uv](https://docs.astral.sh/uv/).

Клонировать репозиторий:

```bash
git clone https://github.com/kuksovaa/lifemate-mini.git
cd lifemate-mini
```

Ссылка на клонирование станет рабочей после публикации репозитория.

Установить зависимости:

```bash
uv sync
```

Запустить приложение:

```bash
uv run uvicorn app_final:app --host 127.0.0.1 --port 8000
```

Приложение будет доступно по адресу:

`http://127.0.0.1:8000`

Интерактивная документация FastAPI:

`http://127.0.0.1:8000/docs`

Остановить сервер можно сочетанием `Ctrl + C` в терминале.

## Примеры использования

Добавление записи в дневник:

**POST `/journal`**

```json
{
  "text": "Сегодня изучала FastAPI"
}
```

Добавление демонстрационного контакта:

**POST `/people`**

```json
{
  "name": "Тестовый контакт",
  "last_meeting": "2026-10-01",
  "interests": ["музыка", "спорт"]
}
```

Получение напоминаний:

**GET `/reminders?days=30`**

Приложение вычисляет количество дней с последней встречи и возвращает напоминания для контактов, у которых превышен заданный порог.

## Автоматические тесты

Запуск всех тестов:

```bash
uv run python -m pytest -v
```

Тесты проверяют доступность приложения, версию, операции с дневником, поиск людей, напоминания и рекомендации.

## Конфигурация и логирование

Название приложения настраивается через переменную окружения `APP_NAME`.

Пример запуска:

```bash
APP_NAME="LifeMate Mini" uv run uvicorn app_final:app --host 127.0.0.1 --port 8000
```

В приложении используется модуль `logging`. Сообщения о запросах и создании записей выводятся в терминал.

## Диагностика

**Приложение не запускается:** проверить установку зависимостей через `uv sync` и наличие файла `app_final.py`.

**Порт занят:** остановить предыдущий экземпляр сервера или выбрать другой порт.

**404 Not Found:** проверить правильность адреса и наличие запрашиваемого человека или интереса.

**422 Unprocessable Entity:** проверить параметры запроса и формат входящих данных.

**500 Internal Server Error:** посмотреть traceback в терминале, где запущен Uvicorn.

## Ограничения первой версии

Приложение хранит дневник и добавленные контакты в оперативной памяти. После перезапуска сервера изменения теряются.

Настоящая ИИ-модель, база данных, автоматическая отправка уведомлений и интеграции с внешними сервисами пока отсутствуют.

Проект предназначен для обучения. В публичном репозитории должны использоваться исключительно вымышленные демонстрационные данные. Реальные личные сведения, медицинские документы и секретные ключи не публикуются.

## Дальнейшее развитие

В перспективе LifeMate может получить постоянную базу данных, персональную память, интеграцию с календарём, рекомендательную систему и ИИ для анализа записей с разрешения пользователя.
